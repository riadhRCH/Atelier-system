Introduction à Unix / Linux

Commencer le cours

1. Fondamentaux : historique d'Unix et de Linux

Objectif : situer Unix, GNU et Linux dans le temps et comprendre leurs liens.

Unix naît en 1969 aux laboratoires Bell (AT&T) sous l'impulsion de Ken Thompson et Dennis Ritchie. Réécrit en langage C en 1973, il devient portable sur de nombreuses machines. Sa philosophie : de petits programmes qui font une seule chose bien, et qui se combinent entre eux.

En 1983, Richard Stallman lance le projet GNU pour créer un système libre. Il produit presque tous les outils (compilateur gcc, shell bash, commandes de base), mais il lui manque un noyau. En 1991, l'étudiant finlandais Linus Torvalds publie le noyau Linux. L'association du noyau Linux et des outils GNU forme ce qu'on appelle un système GNU/Linux.

À retenir : « Linux » désigne strictement le noyau. Le système complet est fourni par une distribution. Linux est sous licence libre (GPL) : on peut l'utiliser, l'étudier, le modifier et le redistribuer.

Quelle différence entre Unix et Linux ?

En bref : Unix est le système d'origine. Linux est un système inspiré d'Unix, écrit à part et gratuit. Ils se ressemblent beaucoup, comme deux voitures de marques différentes qui ont le même volant et les mêmes pédales.
UnixLinux
Créé parBell Labs (1969)Linus Torvalds et la communauté (1991)
Code sourcePropriétaire à l'origineLibre et ouvert (GPL)
PrixSouvent payantGratuit
ExemplesSolaris, AIX, HP-UX, macOSUbuntu, Debian, Fedora
CommandesPresque identiques : ls, cd, cp… fonctionnent des deux côtés

Linux n'utilise aucune ligne de code d'Unix : il en reprend seulement les idées et les règles de fonctionnement. On dit que c'est un système « de type Unix » (Unix-like).

Linus Torvalds, le créateur du noyau

Linus Torvalds est né en 1969 à Helsinki (Finlande). En 1991, à 21 ans et encore étudiant, il écrit un petit noyau « pour le plaisir » et le partage sur Internet. Des milliers de développeurs l'ont amélioré depuis. Il a aussi créé Git en 2005, l'outil de gestion de versions le plus utilisé.

La mascotte de Linux est le manchot Tux (page de garde).

2. Architecture d'un système Unix/Linux

Analogie du restaurant : vous (l'utilisateur) commandez au serveur (le shell), qui transmet à la cuisine (le noyau). La cuisine utilise les équipements (le matériel) et prépare le plat. Le système de fichiers est le garde-manger bien rangé.

Le noyau (kernel)

Cœur du système. Il gère le processeur, la mémoire, les périphériques et les fichiers, et sert d'intermédiaire entre les programmes et le matériel.

Le shell

Programme qui lit vos commandes, les interprète et demande au noyau de les exécuter. C'est votre interface en ligne de commande.

Le système de fichiers

Organisation arborescente unique dont le sommet est la racine /. « Tout est fichier » : documents, périphériques, processus.

L'arborescence standard

Deux notions de chemin : absolu (commence par /, ex. /home/alice/tp) et relatif (depuis le répertoire courant, ex. tp/docs). Raccourcis : . (ici), .. (parent), ~ (votre dossier personnel).

Une distribution assemble le noyau, les outils GNU, un gestionnaire de paquets et souvent un environnement graphique. Les principales se regroupent en familles selon leur base.

Debian / UbuntuRed Hat / CentOS

Pour ce cours : nous utilisons Ubuntu LTS (24.04 ou plus récente). Toutes les commandes vues fonctionnent sur les autres distributions.

4. Installer un environnement Linux de base

Quel choix pour vous ? Sous Windows, prenez WSL (2 minutes). Sur un Mac ou pour ne rien risquer, prenez une machine virtuelle. Les autres méthodes viennent ensuite.

Il existe plusieurs façons d'obtenir Ubuntu. Choisissez selon votre situation. Téléchargement officiel de l'image ISO : ubuntu.com/download.

Windows — le plus simple

A. WSL (Windows Subsystem for Linux)

Linux directement dans Windows 10 (2004+) ou 11, sans machine virtuelle à gérer.

  1. Ouvrir PowerShell en administrateur.
  2. Lancer la commande ci-dessous.
  3. Redémarrer si demandé.
  4. Ubuntu s'ouvre : choisir un nom d'utilisateur et un mot de passe.
PS> wsl --install
# une autre version :
PS> wsl --list --online
PS> wsl --install -d Ubuntu-24.04

Lancer ensuite Ubuntu depuis le menu Démarrer ou avec wsl. Méthode manuelle si besoin : activer les fonctionnalités « Sous-système Windows pour Linux » et « Plateforme de machine virtuelle », puis wsl --set-default-version 2. Ubuntu est aussi disponible dans le Microsoft Store.

Tous systèmes — sans risque

B. Machine virtuelle

  1. Installer VirtualBox, VMware Workstation Player ou Hyper-V.
  2. Créer une VM : 2 CPU, 4 Go de RAM, 25 Go de disque minimum.
  3. Monter l'ISO d'Ubuntu comme lecteur optique.
  4. Démarrer et suivre l'assistant d'installation.

Sur Mac (Apple Silicon) : UTM ou Parallels avec l'ISO ARM.

Test rapide

C. Clé USB « Live »

  1. Créer la clé avec Rufus (Windows), balenaEtcher ou Ventoy (8 Go min.).
  2. Redémarrer et ouvrir le menu de démarrage (F12, F2, Échap… selon la machine).
  3. Choisir « Try Ubuntu » : rien n'est installé, tout disparaît à l'extinction.
Installation définitive

D. Installation sur disque (seul ou double démarrage)

  1. Sauvegarder vos données.
  2. Sous Windows : réduire une partition depuis « Gestion des disques » (≈ 40 Go), désactiver le démarrage rapide et BitLocker si actif.
  3. Démarrer sur la clé USB, choisir « Install Ubuntu ».
  4. Choisir « Installer à côté de Windows » (dual boot) ou « Effacer le disque ».

Au démarrage, le menu GRUB permet de choisir Windows ou Ubuntu.

Développeurs

E. Multipass ou Docker

Ubuntu léger en une commande.

$ multipass launch 24.04 --name tp
$ multipass shell tp
# ou avec Docker :
$ docker run -it ubuntu:24.04 bash
Sans installation

F. Cloud et terminal en ligne

Serveur Ubuntu chez un fournisseur cloud (Azure, AWS, DigitalOcean…) accessible par SSH, ou terminaux en ligne pour s'exercer sans rien installer.

$ ssh utilisateur@adresse-du-serveur

Vérifier son installation

$ lsb_release -a
Distributor ID: Ubuntu
Release:        24.04
$ uname -r
# affiche la version du noyau
$ sudo apt update && sudo apt upgrade -y
Conseil : pour débuter, WSL (sous Windows) ou une machine virtuelle suffisent et sont sans risque pour vos données.

5. L'interpréteur Shell

En bref : le shell est une fenêtre où l'on donne des ordres à l'ordinateur en tapant du texte. On écrit une commande, on appuie sur Entrée, l'ordinateur répond.

Le shell affiche une invite (prompt), lit la ligne saisie, l'analyse, lance le programme demandé et affiche le résultat. Le plus courant est bash.

alice@pc:~$ ls -l /etc
# alice = utilisateur, pc = machine, ~ = dossier courant, $ = utilisateur normal (# = root)
  • Options courtes : un tiret, une lettre (-l), combinables : -lah.
  • Options longues : deux tirets (--help, --all).
  • Arguments : fichiers, répertoires ou textes sur lesquels agit la commande.
  • Linux est sensible à la casse : Doc et doc sont différents. Les espaces séparent les mots.

Commandes de base

CommandeRôleExemple
pwdAfficher le répertoire courantpwd
lsLister (-l détaillé, -a fichiers cachés, -h tailles lisibles)ls -lah
cdChanger de répertoirecd /etc, cd .., cd
mkdirCréer un dossier (-p : avec parents)mkdir -p a/b
touchCréer un fichier videtouch f.txt
cp / mvCopier / déplacer ou renommercp a b, mv a c
rmSupprimer (-r dossier). Sans corbeille !rm f.txt
cat, head, lessAfficher un fichierhead -n 3 f.txt
echoAfficher du texte (avec > : écrire dans un fichier)echo salut > f.txt
clear, historyEffacer l'écran / historique des commandes
Astuces : Tab complète les noms, ↑ rappelle la commande précédente, Ctrl+C interrompt un programme.

6. Aide et documentation

Un utilisateur Linux ne mémorise pas tout : il sait chercher. Trois réflexes :

$ man ls              # manuel complet de ls
$ ls --help | less    # aide rapide de la commande
$ whatis ls           # description en une ligne
$ apropos copy        # chercher un mot dans toutes les descriptions
$ type cd             # cd est une commande interne du shell (utiliser help cd)

Lire une page man

SectionContenu
NAMENom et description courte
SYNOPSISSyntaxe. [ ] = facultatif, ... = répétable, | = ou
DESCRIPTIONExplication détaillée et liste des options
EXAMPLES / SEE ALSOExemples et commandes liées

Navigation dans man (fonctionne aussi avec less) : Espace page suivante, b page précédente, /mot rechercher (puis n suivant), q quitter.

Les pages sont classées en sections numérotées : 1 commandes, 5 formats de fichiers, 8 administration. Exemple : man 5 passwd (fichier) ≠ man 1 passwd (commande). Autres sources : info, /usr/share/doc, et la documentation en ligne (ubuntu.com, wiki.debian.org, manpages.debian.org).

7. Méta-caractères du Shell (jokers)

En bref : les jokers sont des « cartes joker » : * remplace n'importe quoi, ? remplace une seule lettre, [ab] remplace une lettre choisie dans une liste.

Le shell remplace les motifs par la liste des fichiers correspondants avant de lancer la commande. On parle de globbing. Ne pas confondre avec les expressions régulières de grep.

MotifSignificationExemple
*0 ou plusieurs caractères quelconques*.txt : tous les fichiers .txt
?exactement 1 caractèref?.c : fa.c, f1.c (pas f10.c)
[abc]1 caractère parmi a, b ou cphoto_[ab].jpg
[a-z], [0-9]1 caractère dans un intervalledoc[0-9].pdf
[!abc]1 caractère sauf a, b, c[!.]*
Les fichiers cachés (débutant par .) ne sont pas captés par *. Pour empêcher l'interprétation, mettre entre guillemets : echo "*" affiche un astérisque.

8. Exercices pratiques au terminal

Ouvrez un terminal Ubuntu (WSL, VM ou autre). Les exercices vont du plus simple au plus difficile : d'abord des commandes seules, puis avec un argument, puis avec des options, enfin avec des jokers. Essayez sans regarder l'indice. Les résultats sont indicatifs : dates et nom d'utilisateur varient.

Niveau 1 — Commandes seules (aucun paramètre)

Tapez juste le nom de la commande, puis Entrée.

Exercice 1 — Où suis-je ?

Affichez le chemin du répertoire dans lequel vous vous trouvez.

Indice
La commande s'écrit en 3 lettres : print working directory.
Résultat attendu
$ pwd
/home/alice

Exercice 2 — Qui suis-je ? Quelle heure est-il ?

Affichez votre nom d'utilisateur, puis la date et l'heure.

Indice
Deux commandes, une par ligne : whoami (« qui suis-je ») et date.
Résultat attendu
$ whoami
alice
$ date
lun. 28 sept. 2026 10:30:12 CEST

Exercice 3 — Voir le contenu du dossier

Listez les fichiers et dossiers présents dans votre dossier actuel.

Indice
ls vient de « list ». Un dossier neuf peut sembler vide : c'est normal.
Résultat attendu
$ ls
Documents  Images  Téléchargements

Exercice 4 — Nettoyer et revoir l'historique

Effacez l'écran, puis affichez la liste des commandes déjà tapées.

Indice
clear nettoie (ou Ctrl+L). history affiche l'historique.
Résultat attendu
$ clear
$ history
    1  pwd
    2  whoami
    3  date
    4  ls
    5  clear
    6  history

Niveau 2 — Avec un argument

La commande reçoit un nom (dossier, fichier, texte) sur lequel travailler.

Exercice 5 — Créer un dossier et y entrer

Créez un dossier nommé tp, placez-vous dedans, puis vérifiez où vous êtes.

Indice
mkdir nom crée, cd nom entre, pwd vérifie.
Résultat attendu
$ mkdir tp
$ cd tp
$ pwd
/home/alice/tp

Exercice 6 — Créer et remplir un fichier

Dans tp, créez un fichier vide a.txt. Puis créez salut.txt contenant le texte « Bonjour Linux » et affichez-le.

Indice
touch a.txt crée un fichier vide. echo "texte" > fichier écrit le texte dans le fichier. cat fichier l'affiche.
Résultat attendu
$ touch a.txt
$ echo "Bonjour Linux" > salut.txt
$ cat salut.txt
Bonjour Linux
$ ls
a.txt  salut.txt

Exercice 7 — Copier, renommer, supprimer

Copiez a.txt en b.txt, renommez b.txt en c.txt, puis supprimez c.txt.

Indice
cp source destination, mv ancien nouveau, rm fichier. Attention : rm n'a pas de corbeille.
Résultat attendu
$ cp a.txt b.txt
$ mv b.txt c.txt
$ rm c.txt
$ ls
a.txt  salut.txt

Exercice 8 — Demander de l'aide sur une commande

Trouvez ce que fait la commande wc en une ligne, puis ouvrez le manuel de ls et quittez-le.

Indice
whatis wc pour la ligne, man ls pour le manuel. Dans man, la touche q quitte.
Résultat attendu
$ whatis wc
wc (1)  - print newline, word, and byte counts for each file
$ man ls
LS(1)   User Commands   LS(1)
NAME
       ls - list directory contents
(appuyer sur q pour quitter)

Niveau 3 — Avec des options (-l, -a, -h, -p…)

Une option, écrite avec un tiret, change le comportement de la commande.

Exercice 9 — Un listing détaillé

Listez le contenu de tp avec les détails (droits, taille, date).

Indice
Option -l (« long »).
Résultat attendu
$ ls -l
total 8
-rw-r--r-- 1 alice alice  0 sept. 28 10:35 a.txt
-rw-r--r-- 1 alice alice 14 sept. 28 10:36 salut.txt

Exercice 10 — Fichiers cachés et tailles lisibles

Affichez aussi les fichiers cachés de votre dossier personnel, avec les tailles en Ko/Mo, en une seule commande, puis revenez chez vous.

Indice
Combinez les options : -l, -a (all), -h (human) donnent -lah. cd seul ramène au dossier personnel.
Résultat attendu
$ cd
$ ls -lah
total 32K
drwxr-x--- 5 alice alice 4,0K sept. 28 10:30 .
drwxr-xr-x 3 root  root  4,0K sept. 28 09:58 ..
-rw-r--r-- 1 alice alice  220 sept. 28 09:58 .bash_logout
-rw-r--r-- 1 alice alice 3,7K sept. 28 09:58 .bashrc

Exercice 11 — Créer plusieurs niveaux d'un coup

Créez tp/projet/img en une seule commande, puis affichez seulement la 1re ligne de salut.txt.

Indice
mkdir -p crée aussi les dossiers parents manquants. head -n 1 fichier affiche la 1re ligne.
Résultat attendu
$ mkdir -p ~/tp/projet/img
$ ls ~/tp
a.txt  projet  salut.txt
$ head -n 1 ~/tp/salut.txt
Bonjour Linux

Niveau 4 — Les jokers * ? [ ]

Un motif remplace plusieurs noms de fichiers à la fois. Préparez d'abord le décor :

$ mkdir -p ~/tp/jok && cd ~/tp/jok
$ touch rapport1.txt rapport2.txt rapport10.txt photo_a.jpg photo_b.jpg photo_c.png notes.md

Exercice 12 — Le joker *

Affichez tous les fichiers qui se terminent par .txt, puis tous ceux qui commencent par photo.

Indice
* remplace n'importe quelle suite de caractères : *.txt et photo*.
Résultat attendu
$ ls *.txt
rapport10.txt  rapport1.txt  rapport2.txt
$ ls photo*
photo_a.jpg  photo_b.jpg  photo_c.png

Exercice 13 — Les jokers ? et [ ]

Affichez (a) les rapports dont le numéro n'a qu'un chiffre, (b) seulement photo_a.jpg et photo_b.jpg, (c) tous les fichiers dont le nom ne commence pas par r.

Indice
(a) ? = un seul caractère. (b) [ab] = a ou b. (c) [!r]*.
Résultat attendu
$ ls rapport?.txt
rapport1.txt  rapport2.txt
$ ls photo_[ab].jpg
photo_a.jpg  photo_b.jpg
$ ls [!r]*
notes.md  photo_a.jpg  photo_b.jpg  photo_c.png

Niveau 5 — Défi final

Mélangez tout ce que vous savez.

Exercice 14 — Trier avec des jokers

Dans ~/tp/jok : copiez toutes les images (jpg et png) dans ~/tp/projet/img, puis supprimez rapport1.txt et rapport2.txt sans toucher à rapport10.txt. Vérifiez à la fin.

Indice
Copie : cp photo_* ~/tp/projet/img. Avant de supprimer, testez le motif avec ls rapport?.txt, puis remplacez ls par rm.
Résultat attendu
$ cp photo_* ~/tp/projet/img
$ ls rapport?.txt
rapport1.txt  rapport2.txt
$ rm rapport?.txt
$ ls
notes.md  photo_a.jpg  photo_b.jpg  photo_c.png  rapport10.txt
$ ls ~/tp/projet/img
photo_a.jpg  photo_b.jpg  photo_c.png
Bonne pratique : avant toute suppression avec un joker, lancez d'abord ls avec le même motif pour voir ce qui sera touché. Ne tapez jamais rm -rf / ni rm -rf * sans savoir où vous êtes.

Niveau 6 — Exercice final noté (13 questions liées)

Un seul projet, 13 étapes à faire dans l'ordre : organiser le dossier d'une école. Chaque étape utilise le résultat de la précédente.

  1. Créez le dossier ecole dans votre dossier personnel et placez-vous dedans.
  2. Dans ecole, créez en une seule commande les dossiers cours, tp et archives.
  3. Créez d'un coup le chemin cours/linux/notes.
  4. Dans tp, créez les fichiers vides tp1.txt, tp2.txt, tp3.txt et rapport.md, sans quitter ecole.
  5. Créez cours/linux/notes/intro.txt contenant la ligne : Linux est un noyau
  6. Ajoutez à la fin de ce fichier la ligne : Unix date de 1969 (sans effacer la première).
  7. Copiez intro.txt dans archives sous le nom intro_copy.txt.
  8. Renommez tp/rapport.md en tp/rapport_final.md.
  9. Avec un joker, copiez tous les fichiers .txt de tp dans archives.
  10. Supprimez tp/tp3.txt (sa copie dans archives doit rester).
  11. Créez un fichier caché vide nommé .config dans ecole.
  12. Enregistrez la liste des fichiers de archives dans le fichier ecole/liste.txt.
  13. Avec un joker, copiez les fichiers .md de tp dans cours.
Indices
  1. mkdir puis cd
  2. mkdir accepte plusieurs noms
  3. option -p
  4. touch avec des chemins tp/…
  5. echo "…" > fichier
  6. >> ajoute à la fin
  7. cp source destination
  8. mv
  9. cp tp/*.txt …
  10. rm
  11. un nom qui commence par un point
  12. ls dossier > fichier
  13. même idée que la question 9 avec *.md
Résultat attendu (arborescence finale)
