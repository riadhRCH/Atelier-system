Les commandes de base de Windows

10 exercices progressifs avec l'Invite de commandes (CMD). Chaque exercice est une suite de questions à faire dans l'ordre : afficher, naviguer, gérer des fichiers, puis enchaîner les commandes.

Niveau : débutant à intermédiaireDurée : environ 3 h10 exercices, 79 questions corrigées
À la fin, vous saurez :
  • afficher des informations et lister des dossiers avec dir et ses options
  • vous déplacer et lire l'aide d'une commande
  • créer, copier, déplacer, renommer et supprimer des fichiers
  • utiliser les jokers, la redirection et le tube |
Ouvrir l'Invite de commandes : touches Windows+R, tapez cmd, puis Entrée. Faites les exercices dans l'ordre : chacun réutilise les dossiers du précédent.
Commencer

Avant de commencer — Variables et attributs

À lire d'abord · deux notions utilisées dans les exercices

En bref : une variable est une petite étiquette qui contient une valeur (votre nom, un dossier…). On l'écrit entre deux signes %. Un attribut est un drapeau posé sur un fichier (caché, lecture seule…).

1. Les variables d'environnement

Windows en prépare plusieurs pour vous. Pour voir leur valeur, on les affiche avec echo. Le shell remplace %NOM% par sa valeur avant d'exécuter la commande.

VariableContientExemple
%USERNAME%nom de l'utilisateur connectéalice
%COMPUTERNAME%nom de l'ordinateurPC-ALICE
%USERPROFILE%dossier personnelC:\Users\alice
%HOMEDRIVE%lettre du disque systèmeC:
%SystemRoot%dossier de WindowsC:\Windows
%CD%dossier courantC:\Users\alice\tp
%DATE% et %TIME%date et heure actuelles28/09/2026 et 10:30:12,45
%PATH%liste des dossiers où Windows cherche les commandesC:\Windows\system32;…
C:\Users\alice> echo %USERNAME%
alice
C:\Users\alice> echo Je suis %USERNAME% sur %COMPUTERNAME%
Je suis alice sur PC-ALICE
C:\Users\alice> cd %USERPROFILE%
C:\Users\alice> set USER
USERDOMAIN=PC-ALICE
USERNAME=alice
USERPROFILE=C:\Users\alice
C:\Users\alice> set ECOLE=ISET
C:\Users\alice> echo %ECOLE%
ISET
  • set seul liste toutes les variables ; set USER n'affiche que celles qui commencent par USER.
  • set NOM=valeur crée votre propre variable. Elle disparaît à la fermeture de la fenêtre.

2. Les attributs de fichiers

Chaque fichier porte des attributs qui changent son comportement. On les voit et on les modifie avec attrib : + ajoute un attribut, - le retire.

LettreMot anglaisEffet
RRead-onlylecture seule : on ne peut pas modifier ni supprimer le fichier
HHiddencaché : absent de dir sans l'option /a
SSystemfichier système, aussi masqué par défaut
AArchivemodifié depuis la dernière sauvegarde (posé automatiquement)
C:\Users\alice\tp\docs> attrib a.txt
A          C:\Users\alice\tp\docs\a.txt
C:\Users\alice\tp\docs> attrib +r a.txt
C:\Users\alice\tp\docs> attrib a.txt
A    R     C:\Users\alice\tp\docs\a.txt
C:\Users\alice\tp\docs> attrib -r a.txt
C:\Users\alice\tp\docs> attrib +h a.txt
(a.txt n'apparaît plus avec dir)
C:\Users\alice\tp\docs> dir /a:h
(n'affiche que les fichiers cachés)
Exemple à titre d'illustration : ne le tapez pas maintenant. Vous mettrez les attributs en pratique aux exercices 8 et 10.

Exercice 3 — Chercher de l'aide

Difficulté : ●●○ · 6 questions à faire dans l'ordre

Objectif : apprendre à s'aider seul.

  1. Affichez la liste de toutes les commandes.
  2. Affichez l'aide de la commande dir.
  3. Obtenez la même aide avec une option.
  4. Trouvez l'option de dir qui trie, puis listez par date.
  5. Trouvez l'option de del qui demande confirmation.
  6. Trouvez l'option de tree qui affiche les fichiers.
Indices (un par question)
  1. help sans argument.
  2. help dir.
  3. dir /?.
    Options utilisées : /? (help)
  4. Cherchez « tri » dans l'aide : l'option est suivie de :d.
    Options utilisées : /o:d (order by date)
  5. del /? et cherchez « confirmation ».
    Options utilisées : /? (help)
  6. tree /? puis cherchez « fichiers ».
    Options utilisées : /? (help)
Sens des options et symboles :
  • /? (help) : affiche l'aide de la commande
  • /o (order) : trie ; :s taille, :n nom, :d date
  • /p (prompt) : demande une confirmation
  • /f (files) : affiche aussi les fichiers
Résultat attendu
:: Q1
C:\Users\alice> help
ASSOC  Affiche ou modifie les associations...
CD     Affiche le nom du répertoire courant...
:: Q2
C:\Users\alice> help dir
Affiche la liste des fichiers et des sous-répertoires d'un répertoire.
:: Q3
C:\Users\alice> dir /?
(même aide que la question précédente)
:: Q4
C:\Users\alice> dir /o:d
(éléments du plus ancien au plus récent)
:: Q5
C:\Users\alice> del /?
  /P  Demande confirmation avant de supprimer chaque fichier.
:: Q6
C:\Users\alice> tree /?
  /F  Affiche les noms des fichiers dans chaque dossier.

Réponses : tri = /o, confirmation = /p, fichiers = /f.

Exercice 7 — Supprimer avec précaution

Difficulté : ●●● · 7 questions à faire dans l'ordre

Objectif : comprendre les options de sécurité.

  1. Supprimez ..\archives\c.txt en demandant confirmation, répondez N.
  2. Recommencez et répondez O.
  3. Supprimez ..\archives\a_copie.txt sans confirmation.
  4. Vérifiez que archives est vide.
  5. Supprimez le dossier vide ..\archives.
  6. Créez ..\test contenant un fichier x.txt, puis essayez rmdir ..\test.
  7. Supprimez ..\test avec son contenu, sans question.
Indices (un par question)
  1. del avec l'option de confirmation.
    Options utilisées : /p (prompt)
  2. Même commande.
    Options utilisées : /p (prompt)
  3. del sans option : attention, pas de corbeille.
  4. Liste simple.
    Options utilisées : /b (bare format)
  5. rmdir marche sur un dossier vide.

Sens des options et symboles :
  • /p (prompt) : demande O/N avant de supprimer
  • /s (subdirectories) : inclut le contenu des sous-dossiers
  • /q (quiet) : sans demander de confirmation

Exercice 8 — Jokers et attributs

Difficulté : ●●● · 8 questions à faire dans l'ordre

Objectif : agir sur plusieurs fichiers à la fois.

  1. Créez les fichiers vides rapport1.txt, rapport2.txt et rapport10.txt.
  2. Créez photo_a.jpg et photo_b.jpg.
  3. Affichez tous les fichiers .txt.

  7. Cachez rapport1.txt.
  8. Affichez uniquement les fichiers cachés.

Sens des options et symboles :
  • /b (bare format) : noms seulement
  • +h (add Hidden attribute) : ajoute l'attribut « caché »
  • /a:h (attributes: hidden) : n'affiche que les fichiers cachés
  • /c (count) : compte les lignes
  • /f (files) : affiche aussi les fichiers (avec tree)
