1. Structure du disque — Le FHS

Objectif : connaître l’organisation standard des dossiers sous Linux (Filesystem Hierarchy Standard).

Sous Linux, tous les fichiers et dossiers sont organisés sous une seule racine : /. Cette organisation suit une norme appelée FHS (Filesystem Hierarchy Standard).

RépertoireRôle principal
/Racine de tout le système
/binCommandes essentielles (ls, cp, mv…)
/sbinCommandes d’administration (réservées au root)
/etcFichiers de configuration du système
/homeDossiers personnels des utilisateurs
/rootDossier personnel de l’administrateur (root)
/varDonnées variables (logs, mails, cache…)
/tmpFichiers temporaires
/usrProgrammes et bibliothèques de l’utilisateur
/devPériphériques (disques, USB…)
/procInformations système (virtuel)
/bootFichiers de démarrage du système
À retenir : Votre dossier personnel se trouve toujours dans /home/votre_nom. C’est là que vous avez le droit d’écrire librement.
$ ls /
# bin  boot  dev  etc  home  lib  media  mnt  opt  proc  root  run  sbin  tmp  usr  var

2. Navigation dans l’arborescence

Objectif : se déplacer efficacement avec cd, comprendre les chemins absolus et relatifs.

Répertoire courant et parent

  • Répertoire courant : l’endroit où vous vous trouvez en ce moment (pwd)
  • Répertoire parent : le dossier au-dessus (..)
  • . signifie « ici » (le dossier courant)
  • ~ signifie « mon dossier personnel »
$ pwd
/home/etudiant
$ cd Documents
$ pwd
/home/etudiant/Documents
$ cd ..
$ pwd
/home/etudiant
$ cd /
$ pwd
/
$ cd
$ pwd
/home/etudiant

Chemins absolus vs relatifs

TypeCommence parExempleSignification
Absolu//home/etudiant/tpDepuis la racine
Relatifrien ou . ou ..tp ou ../DocumentsDepuis l’endroit actuel

Chemin absolu

Fonctionne toujours, peu importe où vous êtes.
cd /home/etudiant/Documents

Chemin relatif

Dépend de votre position actuelle.
cd Documents (si vous êtes déjà dans /home/etudiant)

$ cd /etc          # chemin absolu
$ cd ../home       # chemin relatif (remonter puis aller dans home)
$ cd ~             # raccourci vers le dossier personnel
$ cd               # idem : retour à la maison

3. Commandes de consultation

Objectif : lire le contenu des dossiers et des fichiers sans les modifier.
CommandeRôleExemple utile

headAfficher le débuthead -n 5 fichier.txt
tailAfficher la fintail -n 10 fichier.txt

Options importantes de ls

$ ls -l          # format long (droits, taille, date)
$ ls -a          # affiche aussi les fichiers cachés (ceux qui commencent par .)
$ ls -h          # tailles lisibles (K, M, G)
$ ls -lah        # les trois options combinées
$ ls -R          # affiche aussi les sous-dossiers (récursif)
Astuce : Préférez less à more. Avec less vous pouvez monter et descendre, chercher un mot avec /, et quitter avec q.

$ mkdir -p ~/projet/docs
$ touch ~/projet/docs/intro.txt
$ echo "Premier texte" > ~/projet/docs/intro.txt
$ cp ~/projet/docs/intro.txt ~/projet/docs/intro_copie.txt
$ mv ~/projet/docs/intro_copie.txt ~/projet/docs/backup.txt
$ rm ~/projet/docs/backup.txt
Attention : rm ne met pas à la corbeille. Une fois supprimé, c’est généralement définitif. Toujours vérifier avec ls avant de supprimer avec un joker.

5. Liens physiques et symboliques

Objectif : comprendre la différence entre lien physique et lien symbolique, et savoir utiliser ln.

Un lien permet d’avoir plusieurs noms qui pointent vers le même contenu.

Lien physique (hard link)

Plusieurs noms pour le même fichier sur le disque.

  • Créé avec ln source cible
  • Ne fonctionne pas entre partitions différentes
  • Ne fonctionne pas sur les dossiers

Lien symbolique (soft link)

Un raccourci qui pointe vers un autre fichier ou dossier.

  • Créé avec ln -s source cible
  • Fonctionne partout
  • Peut pointer vers un dossier
  • Se casse si la cible est supprimée
$ echo "contenu important" > original.txt
$ ln original.txt physique.txt          # lien physique
$ ln -s original.txt symbolique.txt     # lien symbolique
$ ls -l
# -rw-r--r-- 2 user user 18 ... original.txt
# -rw-r--r-- 2 user user 18 ... physique.txt
# lrwxrwxrwx 1 user user 12 ... symbolique.txt -> original.txt
En pratique : On utilise presque toujours les liens symboliques (ln -s). Ils sont plus souples et plus sûrs pour débuter.

6. Exercices pratiques (TP)

Ouvrez un terminal et réalisez les exercices dans l’ordre. L’objectif est de manipuler vraiment l’arborescence.

Exercice 1 — Exploration

1. Affichez le contenu de la racine.
2. Allez dans /etc puis revenez dans votre dossier personnel.
3. Affichez votre répertoire courant à chaque étape.

Correction
$ ls /
$ cd /etc
$ pwd
$ cd
$ pwd

Exercice 2 — Création d’arborescence

Créez l’arborescence suivante en utilisant le moins de commandes possible :

~/cours/
├── linux/
│   ├── notes/
│   └── tp/
└── reseaux/
Correction
$ mkdir -p ~/cours/linux/notes ~/cours/linux/tp ~/cours/reseaux

Exercice 3 — Manipulation de fichiers

1. Dans ~/cours/linux/tp, créez les fichiers exo1.txt, exo2.txt et rapport.txt.
2. Écrivez « Chapitre 3 » dans rapport.txt.
3. Copiez rapport.txt vers ~/cours/linux/notes/.
4. Renommez la copie en rapport_final.txt.
5. Supprimez exo2.txt.

Correction
$ cd ~/cours/linux/tp
$ touch exo1.txt exo2.txt rapport.txt
$ echo "Chapitre 3" > rapport.txt
$ cp rapport.txt ~/cours/linux/notes/
$ mv ~/cours/linux/notes/rapport.txt ~/cours/linux/notes/rapport_final.txt
$ rm exo2.txt

Exercice 4 — Liens

1. Créez un fichier original.txt contenant le texte « Lien test ».
2. Créez un lien symbolique nommé raccourci.txt vers ce fichier.
3. Affichez les détails avec ls -l.
4. Affichez le contenu via le lien symbolique.

Correction
$ echo "Lien test" > original.txt
$ ln -s original.txt raccourci.txt
$ ls -l
$ cat raccourci.txt
TP Principal — Projet complet (à faire en fin de séance)

Ce TP regroupe tout ce que vous avez appris dans le chapitre.

TP — Organisation d’un espace de travail étudiant

Consignes : Réalisez les étapes suivantes dans l’ordre.

  1. Créez le dossier ~/etudes puis placez-vous dedans.
  2. Créez en une seule commande les dossiers : cours, tp, projets, archives.
  3. Créez le chemin complet cours/linux/notes et cours/linux/exercices.
  4. Dans tp, créez les fichiers vides : tp1.txt, tp2.txt, tp3.txt, compte_rendu.md.
  5. Écrivez dans tp/tp1.txt le texte : Premier TP Linux
  6. Ajoutez à la fin de ce fichier la ligne : Chapitre 3 terminé (sans effacer la première ligne).
  7. Copiez tous les fichiers .txt de tp vers archives (avec un joker).
  8. Renommez tp/compte_rendu.md en tp/compte_rendu_final.md.
  9. Créez un lien symbolique nommé lien_notes dans ~/etudes qui pointe vers cours/linux/notes.
  10. Créez un fichier caché .config dans ~/etudes.
  11. Affichez toute l’arborescence de ~/etudes avec ls -laR.
  12. Vérifiez le contenu de tp1.txt via son chemin dans archives.
Indices
  1. mkdir puis cd
  2. mkdir accepte plusieurs noms
  3. mkdir -p
  4. touch
  5. echo "texte" > fichier
  6. echo "texte" >> fichier (deux chevrons)
  7. cp tp/*.txt archives/
  8. mv
  9. ln -s
  10. Nom qui commence par un point
  11. ls -laR ~/etudes
  12. cat archives/tp1.txt
Correction complète
$ mkdir ~/etudes
$ cd ~/etudes

$ mkdir cours tp projets archives

$ mkdir -p cours/linux/notes cours/linux/exercices

$ touch tp/tp1.txt tp/tp2.txt tp/tp3.txt tp/compte_rendu.md

$ echo "Premier TP Linux" > tp/tp1.txt

$ echo "Chapitre 3 terminé" >> tp/tp1.txt

$ cp tp/*.txt archives/

$ mv tp/compte_rendu.md tp/compte_rendu_final.md

$ ln -s cours/linux/notes lien_notes

$ touch .config

$ ls -laR ~/etudes

$ cat archives/tp1.txt
Objectif du TP : À la fin, vous devez savoir créer une arborescence, manipuler des fichiers, utiliser les jokers et créer un lien symbolique sans regarder le cours.
